## Doküman şablonu

Her faz dokümanı şu başlıkları içerir:

1. **Özet**: fazın amacı ve sonucu
2. **Alınan kararlar**: karar, alternatifler, gerekçe
3. **Yapılanlar**: dosya dosya değişiklikler
4. **Doğrulama**: çalıştırılan komutlar ve sonuçları
5. **Bilinen eksikler / sonraki faza devredilenler**
